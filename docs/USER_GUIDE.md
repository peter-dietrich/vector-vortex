# Vector Vortex — macOS Help

Neon tunnel shooter — protect the rim

## How to play

Move around the tube rim, fire inward to stop climbers, and prevent enemies from reaching the edge. Classic and Modern render the same underlying game mechanics.

## Keyboard and mouse controls

| Control | Action |
|---|---|
| Return | Start, restart or resume. |
| Left / Right or A / D | Move around the rim. |
| Space | Fire inward. |
| Shift | Use the one-per-wave defensive pulse. |
| P | Pause or resume. |
| Click playfield | Restore keyboard focus. |

## Scores, saves and settings

Use the toolbar's Save and Load controls for local checkpoints (up to twelve slots). High score and custom presets persist in the game's local preferences.

## Application menus

The native **Game** menu offers How to Play, Controls & Shortcuts, and Scores & Saving. The **Help** menu opens these offline instructions. Standard macOS App, Edit, Window, and Quit commands remain provided by the operating system. In-game gameplay buttons and shortcuts are unchanged.
